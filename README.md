# BOMiS

범주형 minority 오버샘플링 방법 BOMiS("Certifying Structural Zeros for Categorical Minority Oversampling")의 실험 저장소다. 방법 코드는 원저자 저장소 `github.com/suman-cha/bomis` 커밋 `fa088a9`를 기준으로 쓴다.

## 하위 폴더

| 폴더 | 내용 | 상태 |
|---|---|---|
| [`synthetic/`](synthetic/) | 정답 support를 아는 합성 모집단에서 BOMiS를 단계별로 평가(DGP, 채점기, baseline 비교) | 진행 중. 처음 볼 때는 `synthetic/README.md`부터 |
| `real/` | real 데이터 실험 | 예정 |

여러 실험이 같이 쓰는 코드가 생기면 그때 공통 폴더로 옮긴다.
